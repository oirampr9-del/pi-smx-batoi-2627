# proyecto 
Este proyecto documenta una pequeña red local con un servidor y dos equipos cliente, como práctica de Markdown y Linux.

## Objetivos

- Documentar una red local de forma clara
- Practicar la sintaxis de Markdown
- Usar comandos básicos de Linux

### Tecnologías utilizadas

- Linux (Ubuntu)
- Git y GitHub
- Markdown

## Equipos de la red

| Equipo   | Función  | Dirección IP  |
|----------|----------|---------------|
| Servidor | Servidor | 192.168.1.10  |
| PC01     | Cliente  | 192.168.1.11  |
| PC02     | Cliente  | 192.168.1.12  |
